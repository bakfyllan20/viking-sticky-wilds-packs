# Viking Sticky Wilds — Stake Engine upload packs

Download **Math.zip** and **Front-End.zip** from the [Releases](https://github.com/bakfyllan20/viking-sticky-wilds-packs/releases) page.

## Math.zip
Unzip, then in Stake Engine → Import new files → **Math**, select the `Math` folder.

Must contain:
- `index.json`
- `books_base.jsonl.zst`
- `books_bonus.jsonl.zst`
- `lookUpTable_base_0.csv`
- `lookUpTable_bonus_0.csv`

Game id `0_1_viking_sticky_wilds` · base cost 1 · bonus cost 100 · RTP 96.7% · max 10,000×.

## Front-End.zip
Unzip, then Import → **Front End**, select the `Front End` folder (`index.html` at the root).

Then **Publish Game** for Math and for Front End.
